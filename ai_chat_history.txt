---

## 1. Назначение

Мобильное приложение, скачивающее видео из популярных сервисов в галерею телефона.
- Принимает URL истории или видео и скачивает ролик в системную Галерею.
- Без серверной части. Вся логика на устройстве.
- MVP: только YouTube. Архитектура должна позволять лёгкое добавление Instagram, VK, Facebook.

## 6. Контракт MethodChannel

Канал: `com.vbsoft.videograbber/download`
События: `com.vbsoft.videograbber/download_events` (EventChannel)

| Метод | Вход | Выход |
|---|---|---|
| `probe` | `{url}` | `{title, duration, thumbnailUrl, uploader, formats:[{id, ext, height, fps, vcodec, acodec, filesize, note}]}` |
| `start` | `{url, formatId, jobId}` | `void` |
| `cancel` | `{jobId}` | `void` |
| `listJobs` | — | `[...]` |

События: `{jobId, phase, percent, speedBps, etaSec, title, filePath, error}`
`phase`: `probing | downloading | merging | saving | completed | failed | cancelled`

## 7. Логика лимита и рекламы

```
Нажатие «Скачать»
 ├─ квота доступна
 │    → probe → start загрузки
 └─ квота израсходована
      → preload rewarded, показ
         ├─ onRewarded → start
         ├─ реклама не загрузилась → fail-safe → start
         └─ реклама не показалась → fail-safe → start
Квота списывается ТОЛЬКО по событию completed
```

Кнопка:
```dart
Row([
  Text(gated ? 'Скачать за просмотр рекламы' : 'Скачать'),
  if (gated) Icon(Icons.play_circle_outline),
])
```

Rewarded-реклама грузится заранее, как только кнопка переходит в платный режим,
и перезагружается после каждого показа.

API `yandex_mobileads` v8 (проверено по исходникам пакета 8.5.0):
```dart
await YandexAds.initialize();
await YandexAds.setLogging(kDebugMode);

final loader = RewardedAdLoader();
final ad = await loader.loadAd(adRequest: AdRequest(adUnitId: rewardedUnitId));
await ad.setAdEventListener(eventListener: RewardedAdEventListener(
  onRewarded: (Reward reward) {},
  onAdDismissed: () {},
  onAdFailedToShow: (AdError error) {},
));
await ad.show();
final Reward? reward = await ad.waitForDismiss();
await loader.destroy();

final banner = BannerAd(adSize: BannerAdSize.inline(width: 320, maxHeight: 100));
await banner.load(AdRequest(adUnitId: bannerUnitId));
// отображение: AdWidget(bannerAd: banner)
// состояние: banner.loadStateStream -> BannerAdLoadStateLoading / Loaded(w,h) / Error
```
`AdRequestError.code` — enum `AdRequestErrorCode` (`noFill`, `networkError`, `systemError`, ...).

## 10. Риски и ветвление

### R1. YouTube и JS-рантайм (главный риск)
С 2025 г. YouTube требует JS-дешифровку подписей видеопотоков и PO-токены. Голый yt-dlp
в Chaquopy (без Node/Deno) часть видео не скачает. Определяется в Фазе 0.

| Результат Фазы 0 | Действие |
|---|---|
| Работает из коробки | Идём по плану без изменений |
| Нужен JS-рантайм | Бандлим QuickJS под Android через NDK, регистрируем в yt-dlp |
| Нужен PO-токен | YouTube переводится на нативный InnerTube-экстрактор (Kotlin), yt-dlp остаётся для остальных сервисов |

### R2. Реклама не покажется на эмуляторе
Юниты `R-M-*` работают для зарегистрированной сборки на реальном устройстве.
На эмуляторе ожидается `noFill` → сработает fail-safe. Для проверки UI:
переопределение юнитов через `--dart-define` и `YandexAds.showDebugPanel()` в debug.

### R3. Публикация в Google Play
Скачивание видео нарушает ToS YouTube; гейт за rewarded-рекламу — пограничная практика
монетизации. Рекомендуется распространение APK вне Google Play. Рекламные сети блокируют
аккаунты за трафик с нарушающих ToS приложений — юниты держать на отдельном приложении.

### R4. Размер APK ~40–50 МБ
Python + ffmpeg. Снижается через `abiFilters` до arm64, если не нужна проверка на x86_64.

### R5. Instagram / Facebook (следующие фазы)
Публичный контент почти всегда требует авторизации. Нужна точка входа для импорта cookies.

### R6. ffmpeg
Android 10+ запрещает исполнение из world-writable папок → распаковываем в приватный
`context.filesDir/bin`, `chmod 700`. Источник статической сборки — BtbN/FFmpeg-Builds (GPLv3),
ссылку и условия лицензирования указать в README.

### R7. Защита лимита
SharedPreferences обнуляется очисткой данных приложения. Без сервера полноценная защита
невозможна — это осознанный компромисс MVP.
